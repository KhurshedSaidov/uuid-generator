What is a UUID Decoder?

A UUID decoder examines the structure of a UUID and displays information encoded inside the identifier. This can include its UUID version, variant, hexadecimal representation, and individual fields.

UUID Version

The UUID version is stored in a specific part of the identifier. Common versions include UUID v1, UUID v4, and UUID v7. The version helps identify how the UUID was generated.

UUID v7 Timestamp

UUID v7 contains a Unix timestamp in its most significant bits. A UUID v7 decoder can therefore extract the timestamp and display the approximate creation time represented by the identifier.

UUID Variant

The UUID variant identifies the layout and interpretation of the UUID fields. Modern UUIDs commonly use the Internet Engineering Task Force UUID variant.

UUID Hexadecimal Value

A UUID contains 128 bits of data, usually represented as 32 hexadecimal characters separated by hyphens. The decoder also displays this raw hexadecimal value without separators.

UUID Fields

A UUID is divided into several fields that contain different parts of the identifier. The decoder displays the main UUID fields, including the time-related fields, version field, clock sequence and variant field, and node field.

Inspecting these fields can help you understand how a UUID is structured and identify which version and variant it uses.

Decode UUID v7 Timestamps

UUID v7 contains a Unix timestamp in its most significant bits. When a valid UUID v7 is decoded, this tool converts the timestamp into a readable date and time.
