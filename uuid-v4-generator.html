What is UUID v4?

UUID v4 is a randomly generated Universally Unique Identifier. It uses random data to create a 128-bit identifier and is widely used in databases, APIs, web applications, and distributed systems.

UUID v4 Format

A standard UUID v4 is represented as 32 hexadecimal characters divided into five groups using hyphens. The UUID version and variant bits are defined according to the UUID specification.

UUID v4 vs UUID v7

UUID v4 is based on random data, while UUID v7 includes a timestamp. UUID v7 can therefore be useful when identifiers need to be roughly sortable by creation time.
