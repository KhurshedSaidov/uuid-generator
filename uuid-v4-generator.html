What is UUID v4?

UUID v4 is a Universally Unique Identifier format that is primarily generated using random data. It is widely used when applications need unique identifiers without relying on a timestamp or a centralized identifier service.

UUID v4 Format

UUID v4 consists of 32 hexadecimal characters arranged into five groups separated by hyphens. The version field identifies the UUID as version 4, while the variant field identifies its UUID representation.

UUID v4 vs UUID v7

UUID v4 is primarily based on random data, while UUID v7 combines a timestamp with random data. UUID v4 is useful when identifiers only need to be unique and do not need to contain ordering information.

When to Use UUID v4

UUID v4 can be useful for database records, APIs, distributed systems, temporary identifiers, and other applications where randomly generated unique identifiers are needed.
