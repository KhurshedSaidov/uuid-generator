What is UUID v7?

UUID v7 is a Universally Unique Identifier format that includes a Unix timestamp together with randomly generated data. This makes UUID v7 useful for systems that need unique identifiers that can also be roughly ordered by creation time.

UUID v7 Format

UUID v7 contains a timestamp in its most significant bits followed by random data. The UUID version and variant fields identify it as a version 7 UUID.

UUID v7 vs UUID v4

UUID v4 is primarily based on random data, while UUID v7 combines a timestamp with random data. Because the timestamp is placed at the beginning of the identifier, UUID v7 values can be useful when identifiers need to be roughly sortable by creation time.

When to Use UUID v7

UUID v7 can be useful for database records, APIs, distributed systems, event data, and other applications where unique identifiers and approximate chronological ordering are both useful.
