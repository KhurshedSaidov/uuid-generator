What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit identifier used to uniquely identify objects, records, users, and resources in software applications. UUIDs are commonly used in databases, APIs, distributed systems, and web applications.

UUID v4 vs UUID v7

UUID v4 is generated using random data and is one of the most commonly used UUID versions. UUID v7 combines a timestamp with randomly generated data, which makes UUID v7 useful when identifiers need to be roughly sortable by creation time.
